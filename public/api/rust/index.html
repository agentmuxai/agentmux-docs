Rust API reference

Rustdoc for the four crates in the agentmuxai/agentmux Cargo workspace.

  • agentmux-cef CEF host process — native window, IPC bridge, browser pane backend.
  • agentmux-srv Sidecar — RPC engine, SQLite persistence, sagas, reactive event bus, process tracker.
  • agentmux-launcher Launcher — process lifecycle, Win32 window reality reconciliation, durable JSONL event log.
  • agentmux-common Shared utilities — data paths, runtime mode, common types.

The TypeScript reference (frontend ViewModels, slice stores, command source) is published natively via Starlight at /api/typescript/.
