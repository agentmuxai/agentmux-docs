Rust API reference

This page is a placeholder. The full rustdoc-generated HTML for the AgentMux Rust crates is staged at this path during the release build via:

npm run build:full

If you're seeing this in production, the release build skipped the Rust step (cargo not on PATH, or submodule not initialized). Local dev uses npm run build which deliberately skips this stage so the docs site iterates without a Rust toolchain.

Crates indexed when the build runs

  • agentmux-cef — host (CEF native window + IPC + browser pane)
  • agentmux-srv — sidecar (RPC engine + persistence + sagas)
  • agentmux-launcher — launcher (process lifecycle, Win32 reconciliation)
  • agentmux-common — shared utilities (data paths, runtime mode)

The TypeScript reference (frontend ViewModels, slice stores, command source) is published natively via Starlight at /api/typescript/.
