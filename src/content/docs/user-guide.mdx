<Aside type="caution" title="Alpha Software">
AgentMux is **alpha software** and under heavy active development. Many features described here may be incomplete, unstable, or not yet implemented. Expect breaking changes between releases. We welcome feedback on [GitHub Issues](https://github.com/agentmuxai/agentmux/issues) or [Discord](https://discord.com/invite/96erama9Ar).
</Aside>

The User Guide covers everything you need to install, launch, and configure AgentMux. If you're contributing to the codebase or building tools that drive AgentMux from the outside, see [Internals](/internals/) instead.

<CardGrid stagger>
  <Card title="Install" icon="rocket">
    Get AgentMux running on Windows x64, macOS (Apple Silicon) or Linux x86_64. Downloads are about 140–200 MB, and no system browser engine is needed.

    [Installation →](/installation/)
  </Card>
  <Card title="Launch your first agent" icon="laptop">
    Pick a harness (Claude Code, Codex CLI, Gemini CLI, Antigravity, Kimi Code CLI, OpenClaw, Pi or GitHub Copilot CLI) and sign in.

    [First Agent Setup →](/first-agent/)
  </Card>
  <Card title="Configure your workspace" icon="setting">
    Settings, keyboard shortcuts, auth flows and system metrics.

    [Settings reference →](/settings/)
  </Card>
