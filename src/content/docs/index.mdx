<Aside type="caution" title="Alpha Software">
AgentMux is in **early alpha** and under heavy active development. Many features described in these docs may be incomplete, unstable, or not yet implemented. Expect breaking changes between releases. We welcome bug reports and feedback on [GitHub Issues](https://github.com/agentmuxai/agentmux/issues) or [Discord](https://discord.com/invite/96erama9Ar).

<CardGrid stagger>
  <Card title="Multi-Provider Agents" icon="laptop">
    Run Claude Code, Codex, Gemini, OpenClaw, Kimi, GitHub Copilot, and Pi in parallel panes. See every tool call, file write, and network request in real time.
  </Card>
  <Card title="Browser Pane" icon="external">
    Native `CefBrowserView` embedded as a child window of the AgentMux frame — full Chromium fidelity for links, popups, and DRM, not an iframe.
  </Card>
  <Card title="Audited Dispatch" icon="setting">
    A 4-layer reducer stack (launcher / host / sidecar / frontend slices) with structured event logs at every layer. "What mutated this state?" has exactly one place to look.
  </Card>
  <Card title="Cross-Platform" icon="open-book">
    Native desktop app built on Rust with bundled Chromium 146 via CEF. Builds for Windows, macOS, and Linux.
  </Card>
