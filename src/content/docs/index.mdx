<Aside type="caution" title="Alpha Software">
AgentMux is **alpha software** and under heavy active development. Many features described in these docs may be incomplete, unstable, or not yet implemented. Expect breaking changes between releases. We welcome bug reports and feedback on [GitHub Issues](https://github.com/agentmuxai/agentmux/issues) or [Discord](https://discord.com/invite/96erama9Ar).
</Aside>

<CardGrid stagger>
  <Card title="Multi-Provider Agents" icon="laptop">
    Run Claude Code, Codex CLI, Mux Code, Gemini CLI, Qwen Code, Kimi Code CLI, OpenClaw, Pi, GitHub Copilot CLI and Antigravity side by side, each in its own pane. Watch every tool call and file edit as it happens.
  </Card>
  <Card title="Browser Pane" icon="external">
    A full Chromium browser inside the AgentMux window, not an iframe: a native child window on Windows and a CEF browser view on macOS and Linux.
  </Card>
  <Card title="Agents That Operate the Workspace" icon="setting">
    AgentMux's own MCP server gives agents tools to open panes and tabs, message other agents, run shells, keep memory and schedule work. See the [Agent App API](/internals/agent-app-api/).
  </Card>
  <Card title="Cross-Platform" icon="open-book">
    A Rust desktop app with a bundled Chromium runtime (CEF). Releases for Windows x64, macOS on Apple Silicon and Linux x86_64.
  </Card>
</CardGrid>
